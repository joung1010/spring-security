# Spring Security - Spring MVC 통합

## 개요

Spring Security는 Spring MVC 인수에 대한 현재 `Authentication.getPrincipal()`을 자동으로 해결할 수 있는 `AuthenticationPrincipalArgumentResolver`를 제공합니다.

Spring MVC에서 `@AuthenticationPrincipal`을 메서드 인수에 선언하게 되면 Spring Security와 독립적으로 사용할 수 있습니다.

---

## AuthenticationPrincipalArgumentResolver 구조

### 1. 핵심 구현 코드

```java
public final class AuthenticationPrincipalArgumentResolver implements HandlerMethodArgumentResolver {
    
    private ExpressionParser parser = new SpelExpressionParser();
    private BeanResolver beanResolver;
    
    @Override
    public boolean supportsParameter(MethodParameter parameter) {
        // 🔥 @AuthenticationPrincipal 어노테이션이 있는 파라미터만 지원
        return findMethodAnnotation(AuthenticationPrincipal.class, parameter) != null;
    }
    
    @Override
    public Object resolveArgument(MethodParameter parameter, ModelAndViewContainer mavContainer,
            NativeWebRequest webRequest, WebDataBinderFactory binderFactory) throws Exception {
        
        // 🔥 현재 Authentication 객체 획득
        Authentication authentication = SecurityContextHolder.getContext().getAuthentication();
        if (authentication == null) {
            return null;
        }
        
        // 🔥 Principal 추출
        Object principal = authentication.getPrincipal();
        
        // 🔥 @AuthenticationPrincipal 어노테이션 정보 획득
        AuthenticationPrincipal authPrincipal = findMethodAnnotation(AuthenticationPrincipal.class, parameter);
        
        // 🔥 SpEL 표현식 처리
        String expressionToParse = authPrincipal.expression();
        if (StringUtils.hasLength(expressionToParse)) {
            StandardEvaluationContext context = new StandardEvaluationContext();
            context.setRootObject(principal);
            context.setVariable("this", principal);
            context.setBeanResolver(this.beanResolver);
            
            Expression expression = this.parser.parseExpression(expressionToParse);
            principal = expression.getValue(context);
        }
        
        // 🔥 타입 검증 및 변환
        if (principal != null && !parameter.getParameterType().isAssignableFrom(principal.getClass())) {
            if (authPrincipal.errorOnInvalidType()) {
                throw new ClassCastException(principal + " is not assignable to " + parameter.getParameterType());
            }
            return null;
        }
        
        return principal;
    }
    
    // 🔥 어노테이션 검색 헬퍼 메서드
    private <T extends Annotation> T findMethodAnnotation(Class<T> annotationClass, MethodParameter parameter) {
        T annotation = parameter.getParameterAnnotation(annotationClass);
        if (annotation != null) {
            return annotation;
        }
        Annotation[] annotationsToSearch = parameter.getParameterAnnotations();
        for (Annotation toSearch : annotationsToSearch) {
            if (toSearch.annotationType().isAnnotationPresent(annotationClass)) {
                return parameter.getParameterAnnotation(annotationClass);
            }
        }
        return null;
    }
    
    public void setBeanResolver(BeanResolver beanResolver) {
        this.beanResolver = beanResolver;
    }
}
```

### 2. @AuthenticationPrincipal 어노테이션

```java
@Target({ElementType.PARAMETER, ElementType.ANNOTATION_TYPE})
@Retention(RetentionPolicy.RUNTIME)
@Documented
public @interface AuthenticationPrincipal {
    
    /**
     * SpEL 표현식을 사용하여 Principal에서 특정 속성 추출
     * 예: "username", "authorities", "details.sessionId"
     */
    String expression() default "";
    
    /**
     * Principal 타입이 파라미터 타입과 맞지 않을 때 오류 발생 여부
     */
    boolean errorOnInvalidType() default false;
}
```

## 기본 사용법

### 1. 단순한 Principal 주입

```java
@RestController
public class UserController {
    
    // 🔥 현재 인증된 사용자의 Principal을 직접 주입
    @GetMapping("/current-user")
    public ResponseEntity<String> getCurrentUser(@AuthenticationPrincipal Object principal) {
        if (principal == null) {
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body("인증되지 않은 사용자");
        }
        
        return ResponseEntity.ok("현재 사용자: " + principal.toString());
    }
    
    // 🔥 UserDetails 타입으로 주입
    @GetMapping("/user-details")
    public ResponseEntity<Map<String, Object>> getUserDetails(@AuthenticationPrincipal UserDetails userDetails) {
        if (userDetails == null) {
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body(null);
        }
        
        Map<String, Object> info = new HashMap<>();
        info.put("username", userDetails.getUsername());
        info.put("authorities", userDetails.getAuthorities());
        info.put("enabled", userDetails.isEnabled());
        info.put("accountNonExpired", userDetails.isAccountNonExpired());
        info.put("accountNonLocked", userDetails.isAccountNonLocked());
        info.put("credentialsNonExpired", userDetails.isCredentialsNonExpired());
        
        return ResponseEntity.ok(info);
    }
    
    // 🔥 커스텀 Principal 타입으로 주입
    @GetMapping("/custom-principal")
    public ResponseEntity<Map<String, Object>> getCustomPrincipal(@AuthenticationPrincipal CustomUserPrincipal customUser) {
        if (customUser == null) {
            return ResponseEntity.status(HttpStatus.UNAUTHORIZED).body(null);
        }
        
        Map<String, Object> info = new HashMap<>();
        info.put("userId", customUser.getId());
        info.put("username", customUser.getUsername());
        info.put("email", customUser.getEmail());
        info.put("fullName", customUser.getFullName());
        info.put("roles", customUser.getRoles());
        
        return ResponseEntity.ok(info);
    }
}
```

## 고급 사용법

### 1. 조건부 Principal 주입

```java
@RestController
public class ConditionalPrincipalController {
    
    // 🔥 Principal이 null인 경우 처리
    @GetMapping("/safe-principal")
    public ResponseEntity<String> getSafePrincipal(
            @AuthenticationPrincipal(expression = "username ?: 'anonymous'") String username) {
        return ResponseEntity.ok("사용자: " + username);
    }
    
    // 🔥 타입 불일치 시 null 반환 (에러 없음)
    @GetMapping("/safe-cast")
    public ResponseEntity<String> getSafeCast(
            @AuthenticationPrincipal(errorOnInvalidType = false) CustomUserPrincipal customUser) {
        
        if (customUser == null) {
            return ResponseEntity.ok("커스텀 사용자가 아니거나 인증되지 않음");
        }
        
        return ResponseEntity.ok("커스텀 사용자: " + customUser.getFullName());
    }
    
    // 🔥 복잡한 조건 처리
    @GetMapping("/conditional-data")
    public ResponseEntity<Map<String, Object>> getConditionalData(
            @AuthenticationPrincipal(expression = "hasRole('ADMIN') ? details : null") Map<String, Object> adminDetails) {
        
        Map<String, Object> response = new HashMap<>();
        
        if (adminDetails != null) {
            response.put("isAdmin", true);
            response.put("adminDetails", adminDetails);
        } else {
            response.put("isAdmin", false);
            response.put("message", "관리자가 아니거나 인증되지 않음");
        }
        
        return ResponseEntity.ok(response);
    }
}
```

### 2. Bean 메서드 호출

```java
@Component
public class UserService {
    
    public String getFullUserInfo(CustomUserPrincipal user) {
        return String.format("%s (%s) - %s", 
                           user.getFullName(), 
                           user.getUsername(), 
                           user.getEmail());
    }
    
    public boolean isVipUser(Long userId) {
        // 실제로는 데이터베이스에서 VIP 여부 확인
        return userId != null && userId <= 10; // 예시: ID가 10 이하면 VIP
    }
}

@RestController
public class BeanMethodController {
    
    // 🔥 Bean 메서드 호출을 통한 데이터 가공
    @GetMapping("/full-user-info")
    public ResponseEntity<String> getFullUserInfo(
            @AuthenticationPrincipal(expression = "@userService.getFullUserInfo(#this)") String fullInfo) {
        return ResponseEntity.ok(fullInfo);
    }
    
    // 🔥 Bean 메서드를 통한 조건 확인
    @GetMapping("/vip-status")
    public ResponseEntity<Map<String, Object>> getVipStatus(
            @AuthenticationPrincipal(expression = "@userService.isVipUser(id)") Boolean isVip,
            @AuthenticationPrincipal CustomUserPrincipal user) {
        
        Map<String, Object> response = new HashMap<>();
        response.put("username", user.getUsername());
        response.put("isVip", isVip);
        response.put("message", isVip ? "VIP 사용자입니다" : "일반 사용자입니다");
        
        return ResponseEntity.ok(response);
    }
}
```

```java
// 🔥 현재 사용자 ID만 추출하는 커스텀 어노테이션
@Target(ElementType.PARAMETER)
@Retention(RetentionPolicy.RUNTIME)
@AuthenticationPrincipal(expression = "id")
public @interface CurrentUserId {
}

// 🔥 현재 사용자명만 추출하는 커스텀 어노테이션
@Target(ElementType.PARAMETER)
@Retention(RetentionPolicy.RUNTIME)
@AuthenticationPrincipal(expression = "username")
public @interface CurrentUsername {
}

// 🔥 관리자 권한 확인 커스텀 어노테이션
@Target(ElementType.PARAMETER)
@Retention(RetentionPolicy.RUNTIME)
@AuthenticationPrincipal(expression = "hasRole('ADMIN')")
public @interface IsAdmin {
}

@RestController
public class CustomAnnotationController {
    
    @GetMapping("/user-id")
    public ResponseEntity<String> getUserId(@CurrentUserId Long userId) {
        return ResponseEntity.ok("사용자 ID: " + userId);
    }
    
    @GetMapping("/username")
    public ResponseEntity<String> getUsername(@CurrentUsername String username) {
        return ResponseEntity.ok("사용자명: " + username);
    }
    
    @GetMapping("/admin-check")
    public ResponseEntity<String> checkAdmin(@IsAdmin Boolean isAdmin) {
        return ResponseEntity.ok("관리자 여부: " + (isAdmin ? "예" : "아니오"));
    }
    
    // 🔥 여러 커스텀 어노테이션 조합 사용
    @PostMapping("/admin-action")
    public ResponseEntity<String> performAdminAction(
            @CurrentUserId Long userId,
            @CurrentUsername String username,
            @IsAdmin Boolean isAdmin) {
        
        if (!isAdmin) {
            return ResponseEntity.status(HttpStatus.FORBIDDEN).body("관리자 권한이 필요합니다");
        }
        
        return ResponseEntity.ok(String.format("관리자 %s (ID: %d)가 작업을 수행했습니다", username, userId));
    }
}
```

## Spring MVC 설정

### 1. ArgumentResolver 자동 등록 (Spring Boot)

Spring Boot를 사용하는 경우, `AuthenticationPrincipalArgumentResolver`가 자동으로 등록됩니다.

```java
@Configuration
@EnableWebSecurity
public class SecurityConfig {
    
    @Bean
    public SecurityFilterChain filterChain(HttpSecurity http) throws Exception {
        http
            .authorizeHttpRequests(authorize -> authorize
                .requestMatchers("/public/**").permitAll()
                .anyRequest().authenticated()
            )
            .formLogin(Customizer.withDefaults());
        
        return http.build();
    }
    
    @Bean
    public UserDetailsService userDetailsService() {
        return new CustomUserDetailsService();
    }
}
```

### 2. ArgumentResolver 수동 등록 (Spring MVC)

Spring Boot를 사용하지 않는 경우, 직접 등록해야 합니다.

```java
@Configuration
@EnableWebMvc
public class WebMvcConfig implements WebMvcConfigurer {
    
    @Override
    public void addArgumentResolvers(List<HandlerMethodArgumentResolver> resolvers) {
        // 🔥 AuthenticationPrincipalArgumentResolver 수동 등록
        AuthenticationPrincipalArgumentResolver resolver = new AuthenticationPrincipalArgumentResolver();
        
        // 🔥 Bean 해결사 설정 (SpEL에서 @bean 참조 가능하도록)
        resolver.setBeanResolver(new BeanFactoryResolver(applicationContext));
        
        resolvers.add(resolver);
    }
    
    @Autowired
    private ApplicationContext applicationContext;
}
```

## 실제 활용 예제

### 1. RESTful API에서의 활용

```java
@RestController
@RequestMapping("/api/posts")
public class PostController {
    
    private final PostService postService;
    
    public PostController(PostService postService) {
        this.postService = postService;
    }
    
    // 🔥 현재 사용자의 게시글 목록 조회
    @GetMapping("/my")
    public ResponseEntity<List<Post>> getMyPosts(@CurrentUserId Long userId) {
        List<Post> posts = postService.findByUserId(userId);
        return ResponseEntity.ok(posts);
    }
    
    // 🔥 게시글 생성 (작성자 자동 설정)
    @PostMapping
    public ResponseEntity<Post> createPost(
            @RequestBody CreatePostRequest request,
            @CurrentUserId Long authorId,
            @CurrentUsername String authorName) {
        
        Post post = new Post();
        post.setTitle(request.getTitle());
        post.setContent(request.getContent());
        post.setAuthorId(authorId);
        post.setAuthorName(authorName);
        post.setCreatedAt(new Date());
        
        Post savedPost = postService.save(post);
        return ResponseEntity.status(HttpStatus.CREATED).body(savedPost);
    }
    
    // 🔥 게시글 수정 (권한 확인)
    @PutMapping("/{postId}")
    public ResponseEntity<Post> updatePost(
            @PathVariable Long postId,
            @RequestBody UpdatePostRequest request,
            @CurrentUserId Long currentUserId,
            @IsAdmin Boolean isAdmin) {
        
        Post post = postService.findById(postId);
        if (post == null) {
            return ResponseEntity.notFound().build();
        }
        
        // 🔥 작성자 본인이거나 관리자인 경우만 수정 가능
        if (!Objects.equals(post.getAuthorId(), currentUserId) && !isAdmin) {
            return ResponseEntity.status(HttpStatus.FORBIDDEN).build();
        }
        
        post.setTitle(request.getTitle());
        post.setContent(request.getContent());
        post.setUpdatedAt(new Date());
        
        Post updatedPost = postService.save(post);
        return ResponseEntity.ok(updatedPost);
    }
}
```

### 2. 웹 페이지에서의 활용

```java
@Controller
@RequestMapping("/web")
public class WebController {
    
    // 🔥 사용자 대시보드 페이지
    @GetMapping("/dashboard")
    public String dashboard(Model model, @AuthenticationPrincipal CustomUserPrincipal user) {
        model.addAttribute("user", user);
        model.addAttribute("welcomeMessage", "환영합니다, " + user.getFullName() + "님!");
        
        // 사용자 역할에 따른 메뉴 설정
        if (user.hasRole("ADMIN")) {
            model.addAttribute("showAdminMenu", true);
        }
        
        return "dashboard";
    }
    
    // 🔥 프로필 편집 페이지
    @GetMapping("/profile")
    public String profile(Model model, 
                         @CurrentUserId Long userId,
                         @AuthenticationPrincipal CustomUserPrincipal user) {
        
        model.addAttribute("userId", userId);
        model.addAttribute("user", user);
        
        return "profile";
    }
    
    // 🔥 관리자 전용 페이지
    @GetMapping("/admin")
    public String admin(Model model, 
                       @IsAdmin Boolean isAdmin,
                       @AuthenticationPrincipal CustomUserPrincipal user) {
        
        if (!isAdmin) {
            return "redirect:/access-denied";
        }
        
        model.addAttribute("admin", user);
        return "admin";
    }
}
```
